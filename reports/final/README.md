# Final Reports

This folder contains the final artifacts retained for the banking PAD prototype.

## Final retained version

The retained deployment-oriented version is V6: behavior-pose fusion with quality-aware decision.

## Structure

- `v6_final_model/internal`: internal V6 evaluation and figures.
- `v6_final_model/external`: external V6 evaluation and figures.
- `v6_final_model/quality_policy`: quality-aware decision tuning.
- `banking_decision`: ACCEPT / RETRY / REJECT business decision reports.
- `explainability`: ablation, behavior-rPPG analysis and Grad-CAM summaries.
- `figures`: selected figures for the report and presentation.

## Perspective

V8 dual temporal is kept under `reports/perspectives/v8_dual_temporal` as a future improvement, not as the final deployment version.
